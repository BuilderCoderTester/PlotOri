# What is PlotOri?

PlotOri is a **Digital Humanities (DH)** platform that transforms readers from passive consumers into active literary creators. The platform allows users to reinterpret, rewrite, and creatively expand literary works while still respecting the original author’s style, themes, and narrative logic.

Instead of treating literature as something fixed and closed, PlotOri treats literature as a living conversation. Users can explore alternate endings, rewrite scenes, imagine “what-if” scenarios, reinterpret villains, create intertextual character meetings, and expand minor characters into central narrators.

The platform combines:
- Literary creativity
- Collaborative learning
- Critical interpretation
- Educational engagement
- Community-driven storytelling

PlotOri is inspired by literary theories such as:
- **Mikhail Bakhtin’s Dialogism**
- **Gérard Genette’s Transtextuality**

The project aims to create a scholarly yet creative ecosystem where literature continues evolving through readers’ interpretations and rewritings.

# Why Are We Building PlotOri?

## 1. To Make Literature Interactive
Most literary platforms only allow reading and discussion. PlotOri allows users to actively participate in the literary process through rewriting and reinterpretation.

## 2. To Encourage Creative Critical Thinking
Students and readers often ask:
- “What if this character survived?”
- “What if the villain told the story?”
- “What if the ending changed?”

PlotOri converts these questions into structured creative exercises.

## 3. To Improve Literary Understanding
Rewriting literature requires:
- Understanding character psychology
- Understanding themes
- Understanding narrative structure
- Understanding writing style

This makes literary analysis more practical and engaging.

## 4. To Build a Collaborative Literary Community
The platform encourages:
- Peer review
- Constructive criticism
- Literary discussions
- Creative collaboration

## 5. To Support Educational Institutions
The Student Zone allows schools and teachers to use the platform for:
- Assignments
- Creative writing exercises
- Literary pedagogy
- Portfolio tracking
- Classroom workshops

## 6. To Create a Participatory Literary Archive
PlotOri aims to become a living archive of literary reinterpretations where readers continuously expand classical works through creative imagination.

# Major Features Planned

## Core Literary Features

### 1. Alternative Endings
Users can rewrite endings of literary works.

### 2. Counterfactual Writing
“What if” style literary exploration.

### 3. Villain Revisions
Retelling stories from the antagonist’s perspective.

### 4. Intertextual Meetings
Characters from different literary works interact together.

### 5. Temporal Transposition
Placing literary works into different historical or cultural settings.

### 6. Missing or Recovered Scenes
Writing scenes implied but never shown in the original text.

### 7. Minor Character Expansion
Transforming side characters into main narrators.

# Tech stack used :  
Frontend : The frontend of PlotOri will be developed using React for building dynamic user interfaces, Tailwind CSS for modern responsive styling, TypeScript for type-safe development, and Vite for fast development and optimized builds.

Backend : The backend system will be built using Spring Boot and Java to provide scalable REST APIs, secure authentication, business logic handling, and efficient server-side processing.

Database : PostgreSQL will be used as the primary relational database for storing users, literary submissions, reviews, archives, and application data securely.

Authentication : Spring Security along with JWT (JSON Web Token) authentication will be implemented to provide secure user login, authorization, and role-based access control.

Containerization : Docker will be used to containerize the frontend, backend, and database services for consistent development, testing, and deployment environments.

Reverse Proxy : NGINX will function as the reverse proxy server for handling request routing, HTTPS configuration, load balancing, and frontend-backend communication.

Hosting : The entire application infrastructure will be hosted on a Hostinger VPS server for better control, scalability, and deployment flexibility.

Version Control : Git and GitHub will be used for source code management, collaboration, branch management, and project version tracking.

CI/CD : GitHub Actions will be used to automate testing, build pipelines, and deployment workflows for continuous integration and continuous delivery.


PlotOri is not simply a fan-fiction platform. It is a Digital Humanities ecosystem that combines literary criticism, creativity, pedagogy, and collaborative storytelling.

The platform aims to:
- Transform literary reading into active creation
- Encourage interpretive thinking
- Build scholarly creative communities
- Support education through participatory literature

By allowing readers to creatively interact with canonical texts, PlotOri keeps literature alive through reinterpretation, dialogue, and imaginative expansion.
